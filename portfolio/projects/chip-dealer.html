About this project

A 2D pixel-art puzzle game inspired by Puzzle Bobble, with a casino twist, you pay 1 dollar each shot try to collect all the chips in each level and clear the board. Built in C# with the MonoGame framework (January to February 2025), by a team of three.

Each turn, a slot machine lets you bet for reward chips, after complete level there's a shop sells special chips and relics that change how you play, such as a longer aim line, special chips that can be use or permanent upgrades to reduce shop prices.

What I did

- Create and Design Game Manager, Button and Singleton

- Overhaul Mainmenu and add Scoreboard

- Create Leaderboard

- Pause menu, Settings and Volume control

- Aim Guide Line

- Move all texture to a single sprite sheet

- Game flow : Game over, Restart and Win

- Explosive chips mechanic

- Shooting Core Mechanic

The core chip shooting: bouncing off the walls, the aim line, detecting the hit angle and snapping each chip into the board's grid, and showing the next chip (later got some bug fixed from teammate).
